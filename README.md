# LocalVoiceInput

Mac のどのアプリでも、**ショートカットを押して話すだけで、整った日本語の文章が今の入力欄に入る**音声入力アプリです。
文字起こしも文章の整形も**すべて Mac の中で処理**します。音声も文字も外部に送らず、月額料金も文字数の上限もありません。

```text
Option + Space → 好きなだけ話す(最大10分) → Option + Space → 数秒で入力欄に文章が入る
```

- 「えーっと」「あのー」などのつなぎ言葉を消し、「火曜日、いや水曜日」のような言い直しは後の言い方だけを残す
- 話した言葉は言い換えない。整形用の AI が言い換えたり内容を足したりしたら、その結果は捨てて元の言葉を使う
- Claude・ChatGPT・Google Workspace などの製品名は、辞書で正しい表記に直す(自分の言葉も追加できる)
- ⌘V で貼り付けられる入力欄なら、アプリを問わず入る(ブラウザ・チャット・エディタ・ターミナルなど)
- パスワード欄には入力しない。入力できなかったときも文章はクリップボードに残る

> 個人が作ったツールです。Typeless ほか既存サービスとは関係ありません。現状のまま公開しており、サポートや継続的な保守は約束できません(MIT ライセンス)。

## 必要なもの

- Apple Silicon(M1 以降)の Mac、macOS 14 以降
- 空き容量 約4GB(モデル約1.7GB + 部品 + ビルド)
- [Homebrew](https://brew.sh)、Xcode Command Line Tools(`xcode-select --install`)
- メモリ: 16GB 以上を推奨。使っていないときの常駐は数十MBで、処理中だけ最大約1.3GBを使い、終われば解放する

## セットアップ

### A. Claude Code / Codex に任せる(おすすめ)

```bash
git clone https://github.com/ogawa-utnoa/LocalVoiceInput.git
cd LocalVoiceInput
claude   # または codex
```

起動したら「**このリポジトリをセットアップして**」と頼むだけです。AI は [AGENTS.md](AGENTS.md) の手順に沿って、部品の導入からモデルの取得、ビルド、テスト、起動まで進めます。

### B. 自分でコマンドを打つ

```bash
git clone https://github.com/ogawa-utnoa/LocalVoiceInput.git
cd LocalVoiceInput
./setup.sh
```

`setup.sh` が行うこと:

1. Mac の確認(Apple Silicon・macOS 14 以降・Command Line Tools)
2. whisper.cpp と llama.cpp を Homebrew で導入(すでに入っていれば触らない)
3. モデルの取得(Hugging Face の公式配布元から。改ざん・破損はチェックサムで検出)
4. アプリのビルド(`LocalVoiceInput.app`)
5. テスト(日本語の読み上げ音声を使った、録音から整形までの一気通しの検査を含む)
6. 起動(メニューバーに 🎙️ が出る)

オプション: `--full`(メモリの少ない Mac 向けの予備モデルも入れる。合計約2.7GB)、`--skip-tests`、`--no-launch`

### 最後に、2つだけ手で許可する

macOS の仕様で、この2つはアプリからもAIからも許可できません。

1. **マイク**: 初めて録音したときに出る確認で「許可」
2. **アクセシビリティ**(入力欄に文字を入れるために必要): システム設定 > プライバシーとセキュリティ > アクセシビリティ で `LocalVoiceInput` をオン

許可されていない間は、メニューバーの 🎙️ に「⚠️ アクセシビリティ権限が無効」と表示されます。

### Mac の起動時に自動で立ち上げる

```bash
./scripts/install_login_item.sh              # ログイン時に自動起動する
./scripts/install_login_item.sh --uninstall  # やめる
```

メニューから「終了」した場合は、次にログインするまで起動しません。

## 使い方

1. 文字を入れたい場所をクリックする
2. **Option + Space** を押して話す(画面下に「録音中」が出る)
3. もう一度 **Option + Space** を押す → 数秒で文章が入る

- ショートカットは 🎙️ >「設定…」で自由に変更できる
- 入力できなかったときは画面下に「📋 クリップボードに保存」と出る。⌘V で貼れる

### 辞書(聞き間違いを直す)

🎙️ >「設定…」>「辞書」で、**正しい表記**と**聞き間違えやすい書き方**(カンマ区切り)を登録すると、文字起こしのあとで正しい表記に直します。
登録した言葉は文字起こしのヒントとしても使うので、そもそも聞き間違えにくくなります。

公開したくない言葉(社名・取引先・人名など)は、リポジトリの外のファイル `~/.localvoiceinput/dictionary.json` に書けます。起動のたびに読み込みます。

```json
[
  {"word": "山田商事", "reading": "やまだしょうじ, ヤマダ商事"}
]
```

### 自分がよく使う言葉を覚えさせる

Claude Code や Codex を使っているなら、過去に自分が入力した文章から、よく使う固有名詞を拾って辞書に入れられます。

```bash
python3 scripts/suggest_dictionary.py        # 候補の単語と回数を出す(文章は出さない)
```

AI に「[AGENTS.md](AGENTS.md) の辞書づくりをやって」と頼めば、候補の絞り込み・読みの割り当て・登録・アプリの再起動までやってくれます。

- 読むのは自分のMacの中のファイルだけ。外部には送らない
- 実測: 自分の語(Substack・Lancers・Notion など)を入れると、その語を含む文の文字誤り率が 32.2% → 5.1% に下がった
- 語を増やしすぎると逆効果。文字起こしのヒントに使うのは先頭150文字までで、入りきらない語は表記の自動修正にだけ使う

## 精度(実測)

macOS の読み上げ音声4種 × 製品名を含む7文 = 28本で測りました(`python3 scripts/eval_asr.py`)。

| 構成 | 文字誤り率 | 製品名の正解 |
| :--- | ---: | ---: |
| **Whisper large-v3-turbo + 辞書(このアプリの標準)** | **0.7%** | **35/36** |
| Whisper large-v3-turbo(辞書なし) | 27.0% | 0/36 |
| Whisper small + 辞書(メモリが少ないとき) | 6.2% | 34/36 |

- 文字誤り率: 句読点・空白を除いて、正解の文とどれだけずれたか(小さいほど良い)
- 製品名: Claude・ChatGPT・Google Workspace などが、正しい綴りで出た数
- 読み上げ音声での計測です。人の声、とくに話し言葉では誤りが増えます
- 詳しくは [BENCHMARK.md](BENCHMARK.md)

## 仕組み

```text
マイク ──(30秒ごと・2秒重ねて)──▶ Whisper で文字起こし(録音中に裏で進む)
停止 ──▶ 残りを文字起こし → つなぎ合わせ → 辞書で表記を直す → つなぎ言葉・言い直しを整理
     ──▶ 小さなAI(Qwen2.5 1.5B)で句読点などを整える → 話した言葉が変わっていないか検査
     ──▶ ⌘V で今の入力欄へ(失敗してもクリップボードに残る)
```

- 文字起こし: [whisper.cpp](https://github.com/ggml-org/whisper.cpp) + Whisper large-v3-turbo(q5_0)
- 文章の整形: [llama.cpp](https://github.com/ggml-org/llama.cpp) + Qwen2.5-1.5B-Instruct(Q4_K_M)
- どちらも処理のときだけ起動し、終わるとメモリを返す。メモリが足りないときは小さいモデルへ、さらに足りなければAIを使わない整形へ自動で切り替える
- 詳しくは [ARCHITECTURE.md](ARCHITECTURE.md)

## 困ったとき

| 症状 | 対処 |
| :--- | :--- |
| 文章が入らず「📋 クリップボードに保存」と出る | アクセシビリティの許可が無効。自分でビルドし直した後は、設定画面でオンに見えても無効になっている。`tccutil reset Accessibility local.voiceinput.LocalVoiceInput` を実行し、アプリを起動し直してから許可し直す |
| ビルドのたびに許可し直すのが面倒 | 画面上部のメニュー「キーチェーンアクセス」>「証明書アシスタント」>「証明書を作成…」で、名前 `LocalVoiceInput Dev`・固有名の種類「自己署名ルート」・証明書のタイプ「コード署名」の証明書を作り、`build.local.env` に `LVI_SIGN_IDENTITY="LocalVoiceInput Dev"` と書いてからビルドする。以後は署名が変わらないので、許可が外れない(証明書に「信頼」を設定する必要はない) |
| Option + Space が効かない | 他のアプリと重なっている。🎙️ >「設定…」でショートカットを変える |
| 「音声を認識できませんでした」 | システム設定 > サウンド > 入力 で使うマイクと音量を確認する |
| 何が起きたか知りたい | 🎙️ >「ログを開く」(`~/Library/Logs/LocalVoiceInput/app.log`)。時間・文字数・エラーだけを記録し、話した内容は書かない |
| テストで音声の検査が飛ばされる | 日本語の読み上げ音声「Kyoko」が必要。システム設定 > アクセシビリティ > 読み上げコンテンツ から追加できる |
